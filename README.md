# PersianHub (ZT Iran Hub) | هاب هوش مصنوعی فروشگاه‌های آنلاین ایران

پلتفرم ابری چندمستأجری (Multi-tenant SaaS) برای فروشگاه‌های آنلاین ایرانی: هر مشتری داشبورد خصوصی خودش را دارد، داده فروشگاهش را وصل می‌کند، تحلیل فروش می‌بیند و به‌تدریج به خدمات بازاریابی و اتوماسیون مبتنی بر هوش مصنوعی دسترسی پیدا می‌کند.

> **وضعیت:** پایه و اسکلت پروژه (فاز ۰). دامنه، هاستینگ و کشور استقرار هنوز تصمیم‌گیری نشده‌اند و پروژه عمداً به هیچ‌کدام وابسته نیست.

## فناوری‌ها
- **TypeScript** و **Next.js** (App Router)، رابط کاملاً فارسی و راست‌به‌چپ
- **PostgreSQL** با ایزوله‌سازی تننت‌ها از طریق Row-Level Security
- **لایه یکپارچه‌سازی ماژولار** (اول ووکامرس)
- لایه هوش مصنوعی مستقل از ارائه‌دهنده (فاز ۵)

## ساختار پوشه‌ها
```
db/migrations/      اسکیمای دیتابیس و سیاست‌های RLS
docs/               معماری، نقشه راه، امنیت
src/app/            صفحات و APIها (Next.js)
src/integrations/   کانکتورها (ووکامرس و ...)
src/lib/            دیتابیس، رمزنگاری، قالب‌بندی فارسی، لایه AI
scripts/            ابزارهای توسعه (مایگریشن)
```

## راه‌اندازی محلی
پیش‌نیاز: Node.js ۲۰ به بالا و Docker.

```bash
cp .env.example .env          # مقادیر را ویرایش کنید
docker compose up -d db       # راه‌اندازی PostgreSQL
npm install
npm run db:migrate            # ساخت جدول‌ها و سیاست‌های RLS
npm run dev                   # http://localhost:3000
```

برای ساخت کلید رمزنگاری: `openssl rand -base64 32`

**فونت:** فایل `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را در `public/fonts/` قرار دهید. فونت عمداً از Google Fonts بارگذاری نمی‌شود تا پروژه به سرویس خارجی وابسته نباشد.

## اصول طراحی
1. **بدون وابستگی حیاتی به سرویس خارجی:** دیتابیس، فونت، ایمیل و احراز هویت قابل میزبانی روی هر زیرساختی هستند.
2. **ایزوله‌سازی در سطح دیتابیس:** حتی اگر در کد فراموش شود، RLS از نشت داده بین مشتریان جلوگیری می‌کند.
3. **مدل داده استاندارد:** کانکتورها داده هر پلتفرم را به یک شکل داخلی ترجمه می‌کنند؛ تحلیل و AI فقط همین مدل را می‌خوانند.
4. **پول به ریال و عدد صحیح** ذخیره می‌شود؛ نمایش به تومان یا ریال است.
5. **زمان در UTC** ذخیره و با تقویم جلالی نمایش داده می‌شود.
6. **انسان در حلقه:** خروجی هوش مصنوعی پیش‌نویس است و بدون تأیید فروشنده منتشر نمی‌شود.
